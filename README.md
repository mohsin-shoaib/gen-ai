1. Run "python scraper.py" for scrapping all data

2. Create a virtual environment by running the command: "python -m venv venv".

3. Activate the virtual environment by running: "source venv/bin/activate".

4. Install the required dependencies by running: "pip install -r requirements.txt"

5. Download mistral-7b model using "https://huggingface.co/TheBloke/Mistral-7B-Instruct-v0.1-GGUF/blob/main/mistral-7b-instruct-v0.1.Q4_K_M.gguf"

6. Place the downloaded mistral file in mistral-7b directory in project directory.

7. Run "streamlit run app.py" for chatbot
