1. Run "python scraper.py" for scrapping all data

2. Run "pip install streamlit streamlit-chat langchain langchain-community ctransformers faiss-cpu sentence-transformers torch"

3. Download mistral-7b model using "https://huggingface.co/TheBloke/Mistral-7B-Instruct-v0.1-GGUF/blob/main/mistral-7b-instruct-v0.1.Q4_K_M.gguf"

4. Place the downloaded mistral file in mistral-7b directory in project directory.

5. Run "streamlit run app.py" for chatbot
